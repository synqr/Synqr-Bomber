# ⚡ SYNQR BOMBER // Elite Kernel Interface

**SYNQR Bomber** is a next-generation, arrow-key controlled Windows terminal application designed for system automation, prank modules, and advanced local script execution. Featuring a custom cyber-red interface, matrix streams, and dynamic progress loaders.

---

## 🚀 Features

* **Interactive BIOS-Style Navigation:** Use your keyboard's `↑` and `↓` arrow keys to seamlessly navigate the elite menu and press `ENTER` to execute.
* **10 Integrated Modules:** From audio-visual loops and folder attributes to registry overrides and system diagnostics.
* **Matrix & Progress Telemetry:** Real-time loading sequences and visual matrix stream rendering.
* **Embedded Sound & Popup Engine:** Multi-threaded PowerShell background tasks for concurrent audio and message box execution.

---

## 🛠️ Requirements & Prerequisites

* **Operating System:** Windows 10 / 11 (Requires `cmd` or PowerShell).
* **Python:** Version 3.8 or higher installed on your system.
* **Audio Dependency:** An `.mp3` file named `Sound.mp3` located inside your Windows `Music` folder (`~\Music\Sound.mp3`).

---

## ⚙️ Installation & Usage

1. Clone or download the repository/script files to your local machine.
2. Ensure your sound file is placed correctly:
   * Path: `C:\Users\<YourUsername>\Music\Sound.mp3`
3. Open **Command Prompt** (CMD) or **PowerShell** in the directory where `synqr_bomber.py` is saved.
4. Run the application with Python:
   ```cmd
   python synqr_bomber.py
